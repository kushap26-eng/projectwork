Apple Stock Market Analysis

Project Overview
This project analyzes historical stock market data of Apple Inc.(AAPL) to identify stock price trends,patterns
and changes over time. It uses python libraries to calculate important statistics and visualize stock performance
using closing prices, moving averages, trading volume and correlation analysis.

Dataset
Company: Apple Inc.
Ticker Symbol: AAPL
Data Source: Yahoo Finance
period: January 2023 - December 2023
Data Format: CSV
Dataset File: AAPL_Stock_Data.csv


The historical stock data is downloaded using the yfinance library.

Objectives
Analyze historical Apple stock price.
Identify the highest and lowest closing prices.
Calculate moving averages to understand price trends.
Study correlations between stock market variables.
Visualize stock market patterns using graphs and charts.

Tools and Libraries
Python: Programming language used for analysis
Pandas: Data manipulation and analysis
NumPy: Numerical Calculations
Matplotlib: Creating graphs and charts
Seaborn: Statistical visualizations and heatmap
yfinance: Downloading historical stock market data

Project Analysis
The project includes the following analyses
1. Downloading historical Apple stock data.
2. Displaying and inspecting the dataset
3. Checking missing values
4. Calculating 20-day and 50-day moving averages.
5. Calculating average, maximum, and minimum closing prices.
6. Finding dates with the highest and lowest closing prices.
7. Filtering and sorting stock data
8. Identifying days with above-average trading volume.
9. Calculating daily percentage returns.
10. Examining correlations between stock variables.

Visualizations

The project includes:
Apple Stock Closing price chart
Closing Price with 20-Day and 50-Day Moving Averages
Trading Volume Chart
Daily returns Distribution
Stock Data Correltion Heatmap


Expected Outcomes
Understand historical Apple stock price movements.
Identify price trends using moving averages.
Compare stock prices and trading volumes.
Understand daily returns patterns.
Examine relationship between Open, High, Low, and Volume.

Conclusion

This project demonstrate how Python can be used for stock market data analysis. It combines data collection, numerical calculations, data manipulation, and visualization to understand historical Apple stock performance. The analysis is for educational purposes and does not constitute investment advice.
